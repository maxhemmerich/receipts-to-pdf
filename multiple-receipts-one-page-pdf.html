Multiple receipts in one PDF

If you have a pile of receipt photos and want them gathered into a single file, this does it: the whole stack becomes one PDF, opening with a cover page that lists every receipt in date order with its amount and a total, then a full page for each receipt behind it. It happens in the browser tab you already have open.

One PDF, or one page?

There are two things this phrase can mean, and they are not the same.

The first is all of my receipts in one PDF file — one thing to send, instead of a camera roll of images. That is exactly what this tool does.

The second is several receipts fitted onto a single sheet. This tool does not do that: it gives each receipt its own page. A receipt is the evidence, and the numbers that matter on it — the merchant, the total, the tax line — are the first things to become unreadable when four are shrunk onto one sheet. One page per receipt keeps every page readable and prints at full width. If what you actually want is the compact single-sheet form, the tool also downloads the same rows as a CSV.

What is in the file

Cover index
Every receipt in date order with its date, note and amount, then a total for the batch. On a long batch the index continues onto a second page.
One receipt per page
Each photo is fitted to the page and centred. Nothing is cropped or cut off.
A footer on every page
Which receipt it is (4 of 9), its date and its amount — so the pages survive being printed and shuffled on a desk.
The same rows as a CSV
One line per receipt plus the total, so the list opens straight in Excel, Numbers or Sheets.
A file you can email
Photos are resized to 2200 pixels on the long edge, so a stack of receipts stays a few megabytes instead of forty.

Doing it, step by step

1. Put the photos in
Drop them on the tool page, or click choose files. JPG, PNG, WebP and GIF. A file that is not a photo is named in a Skipped: line and the rest of the batch still builds.
2. Check the list
Each photo gets a row: a note, a date, an amount. Where the date came out of the filename the row says so; where it could not, you type it in. Move a row with the arrows, turn a sideways photo with the ↻ button, remove a mistake with the ×.
3. Build it
Give the PDF a title if you want one, pick Letter or A4, and press Build the PDF. The download link appears with the result: how many receipts, how many pages, how big, and the total.

Nothing gets uploaded

Receipts carry your card number, your address and what you buy. There is no server here to send them to — no backend, no API key, no analytics. The tool page carries a content-security policy whose connect-src 'none' directive blocks every network request, so it could not upload your photos even if a bug tried to. The PDF and the CSV are assembled by the JavaScript already running in the tab. The full source is on GitHub.

No — this tool gives each receipt its own page. Several receipts shrunk onto one sheet is the one thing a receipt file cannot afford: the totals, the merchant and the tax line are the first things to become unreadable. Do the receipts have to be in order before I start?
No. A batch is sorted by the date each receipt carries before the PDF is built, so dropping a pile in any order still gives you a PDF that reads oldest to newest.
